# Nabeel OS

A personal life operating system that runs in the browser on your phone: prayer times, adhkar and duas, Qur'an reader with memorisation, timetable, study tools, money, fitness, diary, goals and weekly review.

Plain HTML, CSS and JavaScript in one file. No build step.

## Run it
Open `index.html`, or deploy the folder to Vercel (Framework preset: Other, no build command, output directory `./`).

## Your data
Everything is saved in the browser on your device (localStorage and IndexedDB). Use More > Backup to copy a backup.

## Not included on purpose
- The AI assistant and cloud sync only work when the app is opened inside Claude. On this site they show a "not available" message.
- Copyrighted books (The Sealed Nectar, Fortress of the Muslim, the Forty Hadith text) are NOT in this repo. Do not add them to a public repository.
